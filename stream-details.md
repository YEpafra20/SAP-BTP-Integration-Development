## Course focus

Learn SAP BTP Integration Suite through practical topics and business use cases. The course covers APIs, integration flows, monitoring, transport, Open Connectors, API Management, and SAP Cloud Integration best practices.

## Course objectives

By the end of the course, learners should be able to explain concepts and perform hands-on activities across:

- SAP BTP fundamentals
- Integration Suite and Cloud Foundry
- SAP Cloud Integration overview and pre-packaged content
- Connectivity options and security
- Monitoring and transport
- API Management overview, development, and policies
- Open Connectors instances
- Common resources and formulas
- SAP PI/PO
- Best practices for SAP Cloud Integration and API Management
