## 1. What is SAP?

SAP is a global company that develops software to help organisations run, manage, and improve their businesses.

### Overview of SAP: ERP, business software, AI, and solutions

SAP is best known for enterprise resource planning (ERP) software, cloud business applications, and AI-powered business solutions that help organisations make better decisions, automate work, and adapt to changing business conditions.

SAP solutions connect core business processes such as finance, procurement, supply chain management, manufacturing, human resources, customer experience, and analytics in a single integrated environment.

![Image 1: SAP at a glance](images/1.png)

### What does SAP stand for?

SAP stands for **Systems, Applications and Products in Data Processing**. The original meaning comes from the company's German name when it was founded, *Systemanalyse Programmentwicklung*, which translates to “Systems Analysis Program Development.”

### What does SAP do, and why do companies use it?

SAP helps organisations manage and optimise the processes that keep businesses running. Most companies generate information across many departments, systems, and teams. Finance has its own data; procurement has another set of information; HR, manufacturing, customer service, and operations often rely on different tools and workflows.

SAP helps bring those processes and data together. Instead of relying on disconnected systems, spreadsheets, or manual processes, organisations can use SAP solutions to operate with greater visibility, consistency, and efficiency.

## 2. What is ERP?

SAP ERP is a comprehensive software system that streamlines processes, improves productivity, and provides real-time insights across an organisation.

SAP ERP made its first appearance in 1972, when five former IBM engineers in Germany saw the potential to integrate business operations in software. Their idea was to create a system that could bring a company's operations together in one cohesive software package. This vision led to SAP R/2, an early mainframe-based ERP system.

As technology advanced, SAP R/3 brought ERP to the client-server environment in the 1990s. SAP later introduced SAP S/4HANA, an ERP suite using in-memory computing for faster processing and real-time analytics. SAP S/4HANA Cloud extended this vision with cloud ERP options.

## 5. SAP Business Accelerator Hub

[Open SAP Business Accelerator Hub](https://api.sap.com)

SAP Business Accelerator Hub is a developer-facing portal for discovering APIs and integration content. It provides API documentation and resources for building secure integrations. API authentication and access-token flows depend on the API provider's current configuration.

![Image 31: SAP Business Accelerator Hub](images/31.png)

### Example OAuth 2.0 workflow

1. **Initiate login:** Create an authorisation URL with a client ID, scope, and redirect URI.
2. **User approval:** The user signs in and approves access.
3. **Redirect with code:** The authorisation server returns an authorisation code to the client app.
4. **Exchange code:** The client app makes a request to the token endpoint, for example `/oauth2/token`.
5. **Receive access token:** Use the token to make authorised API calls.

Review the API provider's current documentation for authentication, endpoints, request formats, and rate limits: [Alpha API documentation](https://alphaapi.sasonline.in/api-docs/).
